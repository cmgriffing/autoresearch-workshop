# Workshop fonts

These unmodified WOFF2 files are bundled locally; no font CDN is used at runtime.

- Archivo Bold: [Omnibus-Type/Archivo](https://github.com/Omnibus-Type/Archivo), commit `211127690e8ff106c36c935f7e5e697114cff103`, `fonts/webfonts/Archivo-Bold.woff2`. See `Archivo-OFL.txt`.
- IBM Plex Sans Regular and SemiBold and IBM Plex Mono Regular: [IBM/plex](https://github.com/IBM/plex), commit `763c36ef9117782905ae010056dfbe8fd2653a25`, `packages/plex-{sans,mono}/fonts/complete/woff2/`. See `IBM-Plex-OFL.txt`.

Both distributions use the SIL Open Font License 1.1. Only the weights used by the deck are included.
